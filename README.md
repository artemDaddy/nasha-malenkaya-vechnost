# Маленькое путешествие для двоих

## Запуск

Откройте `index.html` в актуальном браузере. Для проверки локально можно также запустить в папке проекта команду `python -m http.server 8000`, затем открыть `http://localhost:8000/outputs/` (или перейти в `outputs` перед запуском сервера).

## Персонализация

В начале блока `<script>` файла `index.html` найдите объект `ПОДАРОК`. Замените имя девушки и подпись, дату начала отношений, заголовки глав, историю знакомства, текст чата, карточки воспоминаний, приколы, качества, важные даты, письмо и финальную фразу. Поля объяснены русскими комментариями рядом. Для даты начала используйте формат `ГГГГ-ММ-ДД`; оставьте пустую строку, чтобы не показывать число дней.

Положите снимки в папку `images` рядом с `index.html` и укажите соответствующие пути: `images/photo-01.jpg`, `images/photo-02.jpg` и так далее. Можно использовать JPEG, PNG или WebP, желательно уменьшить очень большие файлы перед загрузкой. Если путь пуст или файл отсутствует, останется аккуратная заглушка. Переписка редактируется в `ПОДАРОК.начало.переписка`; сообщения и ответы никуда не отправляются.

## Публикация на GitHub Pages

Поместите `index.html`, `README.md` и папку `images` в корень GitHub-репозитория (либо содержимое `outputs` перенесите в корень). В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`, сохраните. После публикации проверьте выданную GitHub Pages ссылку. Для личного репозитория при переносе в корень важно сохранить пути `images/photo-01.jpg`.

## Проверка на телефоне

Сначала откройте опубликованную ссылку на телефоне. Для локальной проверки компьютер и телефон должны быть в одной Wi-Fi сети: запустите локальный сервер `python -m http.server 8000`, узнайте локальный IP компьютера и на телефоне откройте `http://IP-КОМПЬЮТЕРА:8000/outputs/`. Проверьте прокрутку, кнопки, изображения, переходы назад и вперёд и открытие письма. Локальное открытие через `file://` тоже подойдёт для быстрой проверки в браузере компьютера.

При каждом открытии сайт начинается с обложки и оглавления. Выберите главу кнопкой в оглавлении; после обновления страницы путешествие снова начнётся с обложки.
